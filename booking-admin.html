예약 관리

방배점 예약 요청을 확인하고 이용 상태를 관리합니다.

관리자 로그인

문의 게시판과 같은 관리자 비밀번호를 사용합니다. 로그인 전에는 예약 정보를 불러오지 않습니다.

확정 전 기존 예약표를 대조해 주세요.

온라인 접수만으로 예약이 확정되지는 않습니다. 외부에서 받은 예약은 기존 Google 예약표와 확인한 후 확정해 주세요. 상태 변경·직권 수정·삭제는 고객에게 문자나 이메일을 자동 발송하지 않으며, 결제 완료도 의미하지 않습니다.

고객 요청사항

접수 당시 예상 견적

공휴일 할증과 추가 요청은 별도 확인이 필요합니다. 최종 금액과 결제 방법은 고객에게 직접 안내해 주세요.

고객에게 문자 보내기

문구를 복사한 뒤 휴대폰 문자앱을 열어 붙여넣고 직접 전송하세요.

휴대폰 문자앱 열기

문자앱을 여는 것만으로 발송되지는 않습니다. 전송 버튼은 직접 눌러 주세요. 문자 요금은 휴대전화 요금제에 따르며, PC에서 앱이 열리지 않으면 휴대폰에서 이용해 주세요.

예약 내용 수정 관리자 직권 · 저장하면 예상 견적도 다시 계산됩니다

공휴일 요금·최종 견적·결제 안내는 고객과 별도로 확인해 주세요.

예약 삭제

삭제한 예약은 되돌릴 수 없고, 고객도 더 이상 조회할 수 없습니다. 기록을 남기려면 삭제 대신 '취소' 상태로 바꾸세요.
